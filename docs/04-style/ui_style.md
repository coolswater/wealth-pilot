### 一、界面设计原则
#### 1.1 核心设计原则
#### 信息密度优先

金融交易需要同时监控多个数据源专业用户接受高信息密度界面避免过度留白，充分利用屏幕空间响应速度感知
实时数据更新必须有视觉反馈
价格变动用闪烁/颜色变化提示
操作反馈延迟不超过100ms
防错设计

关键操作（下单、撤单）需二次确认
数值输入范围限制和格式校验
危险操作用醒目颜色警示
专业性与易用性平衡

为新手提供简化模式
为专家提供快捷键和批量操作
可自定义工作区布局
