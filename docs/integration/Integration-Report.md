### 3. 服务生命周期集成到应用初始化 ✅

**修改文件：**

- `main.cpp`

**集成内容：**

- 引入 `ServiceLifecycle` 服务生命周期管理器
- 引入 `AlertNotificationService` 智能预警服务
- 注册服务：
    - DatabaseManager（优先级 1，无依赖）
    - ThemeManager（优先级 5，无依赖）
    - AlertNotificationService（优先级 10，依赖 DatabaseManager）
- 优雅关闭：按依赖逆序关闭所有服务

**优势：**

- 统一的服务启动顺序
- 依赖关系自动管理
- 优雅关闭避免资源泄漏
- 启动失败日志记录
