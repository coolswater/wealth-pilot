## 四、响应式布局策略

### 4.1 断点定义

| 断点名称 | 宽度范围 | 布局调整 |
|----------|----------|----------|
| 超大屏 | ≥1920px | 标准布局，AI面板展开 |
| 大屏 | 1600-1919px | 标准布局，AI面板展开 |
| 中屏 | 1280-1599px | AI面板可折叠 |
| 小屏 | <1280px | 不支持 |

### 4.2 字体适配

```cpp
// 根据屏幕宽度计算字体大小
int fontSize = Layout::calculateFontSize(screenWidth);

// 字体大小映射
// ≥1920px: 14px (默认)
// 1600-1919px: 12px
// <1600px: 10px
```

### 4.3 间距适配

```cpp
// 根据屏幕宽度计算间距
int spacing = Layout::calculateSpacing(screenWidth);

// 间距映射
// ≥1920px: 16px
// 1600-1919px: 12px
// <1600px: 8px
```

## 五、使用示例

### 5.1 在代码中使用布局常量

```cpp
#include "ui/components/LayoutConstants.h"

// 设置窗口最小尺寸
setMinimumSize(Layout::Window::MinWidth, Layout::Window::MinHeight);

// 设置固定高度
toolBar->setFixedHeight(Layout::Height::ToolBar);

// 设置间距
layout->setSpacing(Layout::Spacing::MD);

// 设置边距
layout->setContentsMargins(Layout::Margin::Content());

// 计算分割器尺寸
auto sizes = Layout::calculateSplitSizes(width(), Layout::Ratio::Chart);
splitter->setSizes(sizes);
```

### 5.2 在样式中使用尺寸常量

```cpp
// 动态生成样式
QString style = QString(R"(
    QWidget {
        border-radius: %1px;
        padding: %2px;
        font-size: %3px;
    }
)").arg(Layout::Radius::MD)
   .arg(Layout::Spacing::SM)
   .arg(Layout::FontSize::MD);
```

## 六、布局最佳实践

### 6.1 使用比例而非固定尺寸

```cpp
// 推荐：使用比例
int chartWidth = static_cast<int>(width() * Layout::Ratio::Chart);

// 不推荐：硬编码
int chartWidth = 700;
```

### 6.2 使用常量而非魔法数字

```cpp
// 推荐：使用常量
toolBar->setFixedHeight(Layout::Height::ToolBar);

// 不推荐：硬编码
toolBar->setFixedHeight(48);
```

### 6.3 响应式调整

```cpp
void MyPage::resizeEvent(QResizeEvent* event)
{
    // 根据宽度动态调整
    if (event->size().width() < 1400) {
        d->sidePanel->hide();
    } else {
        d->sidePanel->show();
    }
}
```

## 八、布局优化收益

### 8.1 维护性提升

- 统一的尺寸定义，修改一处即可生效
- 清晰的命名，代码可读性更好
- 减少重复代码

### 8.2 一致性提升

- 所有组件使用相同的尺寸规范
- 视觉效果统一
- 用户体验一致

### 8.3 扩展性提升

- 新增组件只需引用常量
- 响应式布局更容易实现
- 主题切换更简单
