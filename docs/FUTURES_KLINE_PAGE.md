# 期货K线详情页 - 功能说明

## 概述

期货K线详情页是WealthPilot项目的核心功能页面，提供专业的期货K线图表分析、实时行情监控和交易操作功能。

---

## 功能特性

### 1. K线图表功能

#### 多周期支持
- **1分钟** - 超短线交易
- **5分钟** - 短线交易
- **15分钟** - 日内波段（默认）
- **30分钟** - 日内波段
- **1小时** - 短线趋势
- **4小时** - 中线趋势
- **日线** - 中长线趋势
- **周线** - 长线趋势
- **月线** - 超长线趋势

#### 图表交互
- **缩放** - 鼠标滚轮缩放
- **平移** - 鼠标拖拽平移
- **十字光标** - 鼠标移动显示价格和时间
- **键盘快捷键**:
  - `←` `→` - 左右平移
  - `↑` `↓` - 缩放
  - `Home` - 显示最早数据
  - `End` - 显示最新数据

#### 成交量分析
- 成交量柱状图
- 涨跌颜色区分
- 成交量均线

---

### 2. 技术指标

#### 移动平均线（MA）
- **MA5** - 5日均线（黄色）
- **MA10** - 10日均线（青色）
- **MA20** - 20日均线（红色）
- **MA60** - 60日均线（紫色）

#### MACD指标
- **DIF线** - 快线（黄色）
- **DEA线** - 慢线（青色）
- **MACD柱** - 柱状图（红色）

#### RSI指标
- **RSI(14)** - 相对强弱指标
- 超买超卖提示

#### KDJ指标
- **K线** - 快线（黄色）
- **D线** - 慢线（青色）
- **J线** - 超快线（红色）

#### 布林带（BOLL）
- **上轨** - 上轨线（红色）
- **中轨** - 中轨线（黄色）
- **下轨** - 下轨线（青色）

---

### 3. 实时行情

#### 行情数据
- **最新价** - 实时价格
- **涨跌幅** - 涨跌金额和百分比
- **最高价** - 当日最高
- **最低价** - 当日最低
- **成交量** - 当日成交量
- **持仓量** - 持仓数据

#### 五档盘口
- **买盘** - 买一至买五价格和数量
- **卖盘** - 卖一至卖五价格和数量
- **实时更新** - 毫秒级更新

#### 最新成交
- 成交时间
- 成交价格
- 成交数量

---

### 4. 交易操作

#### 下单面板
- **价格输入** - 手动输入或自动填充
- **数量输入** - 手动输入数量
- **可用资金** - 显示可用保证金
- **买入按钮** - 开多仓
- **卖出按钮** - 开空仓

#### 快捷操作
- 点击K线图自动填充价格
- 快捷键下单
- 一键平仓

---

### 5. AI智能分析

#### 分析功能
- **技术分析** - AI自动分析K线形态
- **趋势判断** - 上涨/下跌/震荡判断
- **支撑阻力** - 关键价位提示
- **交易建议** - 买卖点位建议

#### 使用方法
1. 点击工具栏"🤖 AI分析"按钮
2. AI自动分析当前合约走势
3. 显示分析结果和交易建议

## 使用示例

### C++代码示例

```cpp
#include "FuturesKLinePage.h"

// 创建页面
FuturesKLinePage* page = new FuturesKLinePage(this);

// 设置合约
page->setInstrument("IF2504");  // 沪深300股指期货

// 设置周期
page->setPeriod(KLinePeriod::Minute15);

// 连接交易信号
connect(page, &FuturesKLinePage::tradeRequested,
        this, [](const QString& instrument, const QString& direction,
                double price, int volume) {
    qDebug() << "Trade:" << direction << instrument 
             << "@" << price << "x" << volume;
});

// 显示页面
page->show();
```

### QML集成示例

```qml
// 在QML中使用
FuturesKLinePage {
    id: klinePage
    instrument: "IF2504"
    period: KLinePeriod.Minute15
    
    onTradeRequested: {
        console.log("Trade:", direction, instrument, price, volume)
    }
}
```

## 注意事项

1. **数据更新频率**
   - K线数据: 5分钟缓存
   - 行情数据: 实时更新
   - 技术指标: 数据变化时重新计算

2. **性能建议**
   - 避免同时显示过多指标
   - 大数据量时使用数据压缩
   - 定期清理缓存数据

3. **错误处理**
   - 网络断开自动重连
   - 数据异常自动过滤
   - 错误信息日志记录
