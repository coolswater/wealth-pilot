### 2.3 配色设计原则

1. **涨跌颜色**
    - 中国市场习惯：红涨绿跌
    - 红色使用鲜亮但不刺眼的 `#EF4444`
    - 绿色使用翠绿 `#10B981`

2. **信息层次**
    - 重要数据：主色调高亮
    - 次要信息：次文本色
    - 背景层次：三级灰度区分

3. **视觉舒适**
    - 深色主题减少眼睛疲劳
    - 护眼主题适合长时间使用
    - 浅色主题适合白天明亮环境

4. **品牌一致性**
    - 主色调统一使用专业蓝
    - 强调色使用金色体现金融属性
    - 所有主题保持品牌识别度

## 三、主题切换按钮问题修复

### 3.1 问题分析

**问题现象：** 点击主题切换按钮后，主题没有实际切换

**根本原因：**

1. `themeSwitchRequested` 信号只打印日志，没有调用 `ThemeManager::setTheme()`
2. 没有连接 `ThemeManager::themeChanged` 信号到按钮的 `onThemeChanged` 槽

### 3.2 修复方案

```cpp
// TitleBarWidget.cpp - initConnections()

// 连接主题切换请求到 ThemeManager
connect(d->m_themeButton, &ThemeToggleButton::themeSwitchRequested,
        [](ThemeType type) {
            ThemeManager::instance()->setTheme(type);
        });

// 连接 ThemeManager 的主题变化信号到按钮
connect(ThemeManager::instance(), &ThemeManager::themeChanged,
        d->m_themeButton, &ThemeToggleButton::onThemeChanged);
```

### 3.3 验证步骤

1. 点击主题切换按钮
2. 观察界面颜色变化
3. 检查日志输出
4. 重启应用验证主题持久化
