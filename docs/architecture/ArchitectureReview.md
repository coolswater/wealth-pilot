# 架构审核报告

## 1. 发现的问题

### 1.1 性能问题

#### 主题切换卡顿（已修复）

**问题**：`ThemeManager::applyTheme()` 中强制调用 `repaint()` 导致全量重绘
**修复**：

- 使用 `setUpdatesEnabled(false/true)` 批量更新
- 异步通知监听器，避免阻塞主线程
- 使用 `update()` 替代 `repaint()`，允许 Qt 合并重绘请求

### 1.2 设计问题

#### Singleton 模式实现

**现状**：使用静态局部变量，线程安全
**问题**：返回裸指针，可能导致调用者误用
**建议**：

```cpp
// 当前实现
static RiskAnalyzer* instance();

// 建议实现（返回引用，明确生命周期）
static RiskAnalyzer& instance();
```

### 1.3 代码规范问题

#### 信号槽连接

- presentation 层有 320 处 connect 调用
- 部分使用旧式语法，应统一使用新式（编译时检查）

#### 内存管理

- 静态局部变量 Singleton 无析构，依赖程序退出自动回收
- 建议关键服务添加 `shutdown()` 方法显式释放资源
