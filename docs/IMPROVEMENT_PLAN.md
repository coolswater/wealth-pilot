# WealthPilot 架构改进计划

## 改进1: DataHub 背压机制

- 添加消息队列缓冲
- 实现丢弃策略（队列满时丢弃旧数据）
- 实现采样策略（高频数据采样）
- 添加流量控制配置

## 改进2: Manager 类职责重构

- Manager: 资源管理、生命周期
- Service: 业务逻辑、对外接口
- Controller: 协调逻辑、流程编排
- Repository: 数据访问、持久化

## 改进3: DashboardPage 懒加载

- 拆分页面组件为独立模块
- 使用 QStackedWidget 按需创建
- 实现页面预加载策略

## 改进4: 主题切换批量更新

- 添加批量更新队列
- 使用 QTimer::singleShot 合并更新
- 实现 setUpdatesEnabled 优化

## 改进5: 大数据量虚拟化渲染

- 实现 VirtualListModel
- 只请求/渲染可见区域数据
- 添加滚动位置缓存

## 实施顺序

1. 先实现改进3（影响最大，用户感知明显）
2. 然后改进1（核心基础设施）
3. 改进5（性能优化）
4. 改进4（用户体验）
5. 改进2（需要全局重构，风险最高）
