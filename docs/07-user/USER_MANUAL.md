## 1. 软件简介

### 1.1 产品概述

WealthPilot（领航资产管理AI助手）是一款专业级金融信息展示与分析软件，为投资者提供实时行情、技术分析、投资组合管理等全方位服务。

### 1.2 主要功能

- 📊 **实时行情**：股票、期货、外汇、数字货币实时行情
- 📈 **技术分析**：专业K线图表，多种技术指标
- 💼 **投资组合**：持仓管理、资产配置、风险分析
- 🤖 **AI助手**：智能问答、市场分析、投资建议
- ⚙️ **个性化**：多主题、多语言支持

## 3. 安装指南

### 3.1 下载安装

1. 从官网下载最新安装包
2. 双击 `WealthPilot-Setup.exe`
3. 按照安装向导完成安装
4. 首次运行需要配置行情接口

### 3.2 首次配置

1. **选择主题**：深色/浅色/护眼
2. **配置CTP接口**（期货功能）：
    - 点击"设置" → "CTP配置"
    - 输入经纪商代码、用户名、密码
    - 点击"连接测试"
3. **添加自选股**：
    - 点击"自选股"标签
    - 输入股票代码，点击"添加"

## 5. 功能详解

### 5.1 行情看板

#### 功能说明

综合展示市场行情，包括：

- 指数分时图
- 涨跌排行榜
- 板块热力图
- 自选股列表

#### 操作步骤

1. 点击侧边栏"行情看板"
2. 选择市场类型（A股/期货/港股）
3. 点击股票查看详情
4. 双击打开K线图

### 5.2 K线图表

#### 功能说明

专业级K线图表，支持：

- 多周期切换（1分/5分/日/周/月）
- 技术指标叠加
- 十字光标跟踪
- 缩放和平移

#### 操作方法

| 操作   | 方法          |
|------|-------------|
| 缩放   | 鼠标滚轮 / 双指缩放 |
| 平移   | 鼠标拖拽 / 双指滑动 |
| 切换周期 | 点击工具栏周期按钮   |
| 添加指标 | 点击"指标"下拉菜单  |
| 十字光标 | 鼠标移动到图表区域   |

#### 技术指标

| 指标   | 说明                    |
|------|-----------------------|
| MA   | 移动平均线（5/10/20/30/60日） |
| MACD | 指数平滑异同移动平均线           |
| KDJ  | 随机指标                  |
| RSI  | 相对强弱指标                |
| BOLL | 布林带                   |

### 5.3 投资组合

#### 功能说明

管理您的投资组合，包括：

- 持仓列表
- 盈亏计算
- 资产配置饼图
- 收益曲线

#### 添加持仓

1. 点击"添加持仓"按钮
2. 输入股票代码
3. 填写买入价格、数量
4. 点击"保存"

#### 查看分析

- **资产配置**：饼图展示各资产占比
- **收益曲线**：折线图展示收益变化
- **风险评估**：显示投资组合风险等级

### 5.4 AI助手

#### 功能说明

基于AI的智能问答系统，支持：

- 市场分析
- 个股诊断
- 投资建议
- 知识问答

#### 使用方法

1. 点击右侧AI助手面板
2. 在输入框输入问题
3. 点击发送或按回车
4. 查看AI回复

#### 示例问题

- "分析一下贵州茅台的投资价值"
- "今天大盘走势如何？"
- "什么是MACD指标？"

### 5.5 系统设置

#### 主题设置

- **深色主题**：适合长时间使用
- **浅色主题**：适合白天使用
- **护眼主题**：减少蓝光，保护眼睛

#### CTP配置

配置期货交易接口：

1. 经纪商代码
2. 用户名/密码
3. 行情服务器地址
4. 交易服务器地址

## 6. 常见问题

### Q1: 无法连接行情服务器？

**A:**

1. 检查网络连接
2. 确认服务器地址正确
3. 检查防火墙设置
4. 尝试切换服务器

### Q2: K线图显示不完整？

**A:**

1. 检查数据是否下载完成
2. 尝试刷新数据
3. 清除缓存后重试

### Q3: 如何导出数据？

**A:**

1. 右键点击数据表格
2. 选择"导出数据"
3. 选择导出格式（CSV/Excel）
4. 选择保存位置

### Q4: 软件启动慢？

**A:**

1. 减少自选股数量
2. 关闭不必要的指标
3. 清理历史数据
