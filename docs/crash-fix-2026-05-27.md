# 2026-05-27 崩溃修复报告

## 问题描述

程序在 GDB 调试器下启动后约 2 秒崩溃，错误码 `0xC0000002` (STATUS_NOT_IMPLEMENTED)。

## 崩溃日志关键信息

```
[2026-05-27 09:06:47.555] [INFO] Application initialized successfully
[2026-05-27 09:06:49.573] [INFO] [DashboardPage] DataHub subscriptions setup complete
[2026-05-27 09:06:49.573] [INFO] ConnectionPool cleanup starting...
QWaitCondition: Destroyed while threads are still waiting
QThread: Destroyed while thread '' is still running
```

## 根本原因分析

### 1. 线程生命周期问题

- **问题**：AsyncQueryThread 在销毁时未完全停止
- **表现**：`QThread: Destroyed while thread '' is still running`
- **修复**：DatabaseManager::shutdown() 增加线程停止等待和超时处理

### 2. QWaitCondition 销毁时机问题

- **问题**：ConnectionPool::cleanup() 在销毁 QWaitCondition 时线程还在等待
- **表现**：`QWaitCondition: Destroyed while threads are still waiting`
- **修复**：
    - 先标记 `m_shuttingDown = true`
    - 调用 `m_condition.wakeAll()` 唤醒所有等待线程
    - 等待 5 秒让线程返回
    - 再销毁 QWaitCondition

### 3. ServiceLifecycle shutdownAll 死锁风险

- **问题**：shutdownAll() 持有锁时调用 shutdown 函数，可能导致死锁
- **修复**：先获取需要关闭的服务列表，释放锁后再执行 shutdown

## Windows 错误码 0xC0000002 说明

`STATUS_NOT_IMPLEMENTED` 通常表示：

- 某个系统调用在当前环境下未实现
- 可能与 GDB 调试器拦截某些调用有关

## 测试建议

### 1. 非调试模式测试

```bash
# 直接运行程序（不使用 GDB）
./WealthPilot.exe
```

### 2. 如果非调试模式下正常

说明问题是 GDB 环境导致的，代码本身没问题。

### 3. 如果非调试模式下也崩溃

可能需要检查：

- 网络请求是否被防火墙拦截
- 数据库文件是否有权限问题
- Qt 插件是否正确安装
