## 快速开始

### 系统要求

- **操作系统**: Windows 10/11
- **内存**: 最低4GB，推荐8GB
- **硬盘**: 最低500MB可用空间
- **网络**: 稳定的互联网连接

### 安装步骤

1. 下载安装包
2. 运行安装程序
3. 选择安装目录
4. 完成安装

### 首次运行

1. 启动WealthPilot
2. 配置CTP账户信息
3. 配置AI服务（可选）
4. 开始使用

## 功能使用

### 1. 查看行情

#### 查看股票行情

1. 点击侧边栏"股票行情"
2. 在搜索框输入股票代码或名称
3. 查看实时行情数据

**行情数据包括**:
- 最新价
- 涨跌幅
- 成交量
- 成交额
- 买一价/量
- 卖一价/量

#### 查看期货行情

1. 点击侧边栏"期货行情"
2. 选择交易所（上期所、大商所、郑商所等）
3. 选择合约品种
4. 查看实时行情

**期货行情数据包括**:
- 最新价
- 涨跌停板
- 持仓量
- 结算价
- 开高低收

### 2. 技术分析

#### K线图

1. 在行情页面点击"K线图"
2. 选择时间周期（1分、5分、日线等）
3. 查看K线走势

**K线图功能**:
- 缩放：鼠标滚轮
- 平移：鼠标拖动
- 十字光标：显示具体数据

#### 技术指标

点击"指标"按钮，选择要显示的指标：

**常用指标**:
- MA（移动平均线）
- MACD
- RSI
- KDJ
- 布林带
- 成交量

**指标参数设置**:
1. 右键点击指标
2. 选择"设置参数"
3. 调整参数值
4. 点击"确定"

### 3. 交易操作

#### 连接交易账户

1. 点击"设置" -> "交易设置"
2. 输入CTP账户信息：
   - 经纪商代码
   - 用户名
   - 密码
   - 行情前置地址
   - 交易前置地址
3. 点击"连接"
4. 等待连接成功

#### 下单交易

1. 在行情页面点击"交易"
2. 填写订单信息：
   - 合约代码
   - 买卖方向
   - 开平标志
   - 价格
   - 数量
3. 确认下单
4. 查看委托状态

#### 撤单

1. 点击"委托"标签
2. 选择要撤销的订单
3. 点击"撤单"

#### 查看持仓

1. 点击"持仓"标签
2. 查看当前持仓信息：
   - 合约
   - 方向
   - 数量
   - 成本价
   - 浮动盈亏

### 4. AI智能分析

#### 智能对话

1. 在AI助理面板输入问题
2. 按Enter发送
3. 查看AI回复

**示例问题**:
- "分析一下铜期货的走势"
- "推荐几个适合做多的品种"
- "现在的市场情绪如何"

#### 市场分析

1. 在行情页面点击"AI分析"
2. 选择分析类型：
   - 技术分析
   - 基本面分析
   - 市场情绪分析
3. 查看分析报告

**分析报告包括**:
- 趋势判断
- 支撑阻力位
- 交易建议
- 风险提示

#### 投资建议

1. 点击"投资建议"
2. 输入投资偏好和风险承受能力
3. 获取个性化建议

### 5. 自选股管理

#### 添加自选股

1. 在行情页面找到合约
2. 点击"添加自选"
3. 或右键选择"添加到自选"

#### 管理自选股

1. 点击侧边栏"自选股"
2. 查看自选股列表
3. 可以：
   - 删除自选
   - 调整顺序
   - 分组管理

### 6. 投资组合

#### 查看组合

1. 点击侧边栏"投资组合"
2. 查看持仓明细
3. 查看组合分析：
   - 资产配置
   - 收益分析
   - 风险评估

#### 组合优化

1. 点击"组合优化"
2. 设置优化目标
3. 查看优化建议

## 配置说明

### 主题设置

1. 点击"设置" -> "外观设置"
2. 选择主题：
   - 深色主题：适合长时间使用
   - 浅色主题：适合日间使用
   - 护眼主题：减少眼睛疲劳

### 交易设置

**CTP配置**:
- 经纪商代码
- 用户名/密码
- 行情前置地址
- 交易前置地址
- 认证码（如需要）

**环境切换**:
- 开发环境：测试使用
- 生产环境：实盘交易

### AI设置

**AI服务配置**:
- 服务提供商（OpenAI/Claude等）
- API密钥
- 模型选择
- 温度参数

**功能开关**:
- 启用AI分析
- 启用智能推荐
- 启用自动提醒

### 通知设置

**行情提醒**:
- 价格提醒
- 涨跌幅提醒
- 成交量提醒

**交易提醒**:
- 委托成交提醒
- 持仓风险提醒

### 缓存设置

**缓存配置**:
- 内存缓存大小
- 磁盘缓存大小
- 缓存过期时间

## 常见问题

### Q1: 无法连接CTP服务器？

**解决方案**:
1. 检查网络连接
2. 确认前置地址正确
3. 检查账户信息
4. 尝试切换网络

### Q2: 行情数据不更新？

**解决方案**:
1. 检查网络连接
2. 重新订阅行情
3. 重启应用

### Q3: AI分析无响应？

**解决方案**:
1. 检查AI服务配置
2. 确认API密钥有效
3. 检查网络连接
4. 查看错误日志

### Q4: 应用运行缓慢？

**解决方案**:
1. 清理缓存
2. 减少自选股数量
3. 关闭不必要的功能
4. 重启应用

### Q5: 如何备份数据？

**解决方案**:
1. 点击"设置" -> "数据管理"
2. 选择"导出数据"
3. 选择导出内容
4. 保存备份文件

### Q6: 如何恢复数据？

**解决方案**:
1. 点击"设置" -> "数据管理"
2. 选择"导入数据"
3. 选择备份文件
4. 确认导入
