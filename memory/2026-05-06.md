## Dashboard 数据加载流程优化 - 已完成 ✅

### 数据加载策略

实现了完整的数据加载流程：**缓存 → 数据库 → 网络数据源**

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   缓存      │ --> │   数据库    │ --> │   网络      │
│ (CacheManager)│   │ (SQLite)    │   │ (Sina API)  │
└─────────────┘     └─────────────┘     └─────────────┘
      ↑                   ↑                   │
      └───────────────────┴───────────────────┘
                    保存数据
```

### 新增方法

| 方法 | 说明 |
|------|------|
| `loadDataWithFallback()` | 主流程控制：缓存→数据库→网络 |
| `loadFromCache()` | 从 CacheManager 内存缓存加载 |
| `loadFromDatabase()` | 从 SQLite 数据库加载 |
| `loadFromNetwork()` | 从网络数据源加载 |
| `saveToCache()` | 保存数据到缓存 |
| `saveToDatabase()` | 保存数据到数据库 |
